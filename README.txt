Kanish Suf Cosmetics Receipt Book — Home Screen App

This is the fixed/recovered receipt book packaged as a Progressive Web App.
For Chrome to offer Install app/Add to Home screen, the package needs to be hosted on an HTTPS website.

After hosting:
1. Open the address in Chrome on Android.
2. Tap ⋮.
3. Choose Add to Home screen or Install app.
4. Confirm.

Use the receipt book's Backup Data function regularly because receipt records are stored on the device/browser.
